## 为什么需要这一层

## 需要博士补充的信息

填充本目录前，需要提供：

1. **要接入的项目清单**（名称 + 一句话说明）
2. **每个项目中与提示词相关的具体环节**（哪个环节现在靠人写 prompt、效果不稳定、或跨了多个模型）
