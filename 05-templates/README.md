> **待填。** 本目录存放可直接复制使用的提示词，与 `02-techniques/` 的区别是：

---

## 收录标准

不满足以下任一条，不进本目录：

1. 有明确的**输入空间**与**输出契约**
2. 有写明的**失败行为**（信息不足时怎么答）
3. 至少在 **3 个模型族**上验证过，并记录差异
4. 绑定 `03-benchmark/` 中的实验编号
