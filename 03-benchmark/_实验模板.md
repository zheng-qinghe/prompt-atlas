## 建议优先做的五组实验

这五组最能证明能力，也最容易被他人复现：

| 编号 | 实验 | 验证的判断 |
|---|---|---|
| EXP-01 | 手写 CoT vs 调推理档位（同一推理型模型） | 推理型模型上手写 CoT 是冗余/有害 |
| EXP-02 | Prompt 描述 JSON vs 原生 schema 结构化输出 | 硬保证优于软约束 |
| EXP-03 | Few-shot 示例数量 0/1/3/5 的收益曲线 | 边际收益在 3–5 处饱和 |
| EXP-04 | 同一任务在 4 个模型族上的表现差异 | 跨族差异量化，产出 per-model variant |
| EXP-05 | 无判据迭代 vs 有判据迭代 | 迭代的前提是可判定的评分标准 |

## 测试集设计原则

1. **固定输入集**：每次实验用同一批输入，否则数据不可比
2. **必含拒答样例**：正解是"信息不足"的case，最能暴露幻觉
3. **人工标注答案**：自动打分必须有黄金标准兜底
4. **记录全部参数**：temperature、档位、模型版本号，缺一不可复现
5. **多次运行取分布**：单次结果可能是噪声，关键实验跑 ≥3 次
