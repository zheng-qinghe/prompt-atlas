# 元提示词（L0）

> 本层收纳**用于生产下层资产的提示词**——即用提示词生成提示词、生成技能包、生成专家配置。
> 对应六类中的 **F 元层自动化**。

---

## 定位

L0 是整个资产库的产能来源。它的产出不是最终答案，而是**可复用的资产**。

| 层 | 产出物 | 一句话 |
|---|---|---|
| L0 元提示词 | 提示词 / 技能包 / 专家配置 | 生产工具 |
| L1 提示词 | 模型输出 | 生产原料 |

---

## 收录标准

一条元提示词要进这个库，需满足：

1. **产出物是结构化的**，不是自由文本——否则无法入库、无法版本化
2. **产出物可校验**——有明确的判据判断生成结果合不合格
3. **有失败行为定义**——信息不足时要求澄清，而不是编一个看起来合理的资产
4. **人类可审阅**——产出必须是人能看懂并修改的，不能是黑箱配置

---

## 关键设计原则

**1. 交叉验证，不要自评自改**
生成与评分不要用同一个模型。推荐分工：强模型生成 → 独立判据评分 → 弱模型执行。

**2. 元提示词自己也要版本化**
元提示词一改，所有由它生成的资产都可能变化。必须在产出物里记录**生成它的元提示词版本号**，否则几个月后无法追溯。

**3. 产出物必须留人工审阅入口**
自动生成的资产直接进生产是危险的。流程应是：生成 → 人审阅/修改 → 入库 → 锁定版本。
